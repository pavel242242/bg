# Basic Experiments

This folder contains basic Claude Code experiments.

## Experiments to Try

1. **File Operations** - Create, read, edit, and write files
2. **Code Analysis** - Analyze code structure and dependencies
3. **Search Operations** - Use Glob and Grep to find files and content
4. **Git Operations** - Basic git commands and workflows

## Example Tasks

- Ask Claude to create a simple Python script
- Have Claude analyze and refactor existing code
- Use Claude to search for patterns in code
- Practice git operations with Claude's help
