# Keboola KB Starter
This package contains:
- **Keboola_Data_Enablement_Guide.md** — the full library + AI assistant kit in one file.
- **/templates** — copy/paste prompts and doc templates (Design Brief, ELT Unit, Validation, Data App, System/Discovery/Modeling/ELT prompts).

## Suggested use
1. Drop the guide into your docs space (Notion, Git, Keboola Docs).
2. For a new project, duplicate templates from `/templates` and fill them in.
3. Keep contracts, SLIs/SLOs, and runbooks linked from your Flows and Data Apps.
