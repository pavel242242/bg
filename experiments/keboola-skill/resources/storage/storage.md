# Keboola Storage Comprehensive Guide

## Overview

Storage is the central Keboola subsystem that manages everything related to storing data and accessing it. It is implemented as a layer on top of database engines used as backends, including **Snowflake** and **BigQuery**. By default, all new Pay As You Go projects use the BigQuery backend.

All Storage operations can be performed through the UI or programmatically via the Storage API. Every Storage operation must be authorized via a token and is recorded in Events and Jobs.

### Storage Data Components

Storage manages three main types of data in each Keboola project:

1. **Data Tables (Table Storage)** - Organized into buckets
2. **Data Files (File Storage)** - All raw files uploaded to your project  
3. **Component Configurations**

### Storage Technologies

Different storage technologies are used for different data types:

- **Table Storage**: BigQuery and Snowflake
- **File Storage**: Amazon S3 Storage, Azure Blob Storage, and Google Cloud Storage

The database system behind Table Storage is referred to as a **backend** or **project backend**.
